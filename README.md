# Kagi Refined

A modern and warm css theme for Kagi.

![image](/assets/homepage.png)
![image](/assets/results.png)

Features:
- Rounded elements now use corner smoothing (squircle / super-ellipse) - only works in [supported browsers](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/corner-shape-value#browser_compatibility).
- The color palette now uses the Kagi yellow color as an undertone, instead of the blue one the default theme has. This brings more cohesion with the Kagi brand.
- The purple accent colors have been replaced with the Kagi yellow color. This brings more cohesion with the Kagi brand.
- The white space of the `search bar` and `related items` has been tweaked to be more proportional and uniform.
- The color palette has more muted border colors compared to the default theme.
- The width of toggle switches have been changed to be proportional (`knob-size * 2 + padding * 3`).
- The padding on the `Apps` dropdown on the search homepage has been reduced, and the border radius has been slightly increased. The border radius of its items have also been tweaked to be more cohesive (`apps-dropdown.border-radius - apps-dropdown.padding`).
- Box shadows have been removed.
- The `Search Options` button is now center aligned.

# Installation:
Put the CSS from [here](/dist/index.css) into the text input at the bottom of [this page](https://kagi.com/settings/custom_css).
